How to add Fraxtal to MetaMask when it is missing

How to add Fraxtal network to MetaMask with chain ID 252 and the official RPC, then verify your selected wallet balance against Fraxscan before using Fraxswap.

Blockfront Editorial

Nov 19, 2026 · 17:48 UTC2 min read

Add Fraxtal to MetaMask as a custom network using chain ID 252, the official RPC at https://rpc.frax.com and the explorer at https://fraxscan.com. MetaMask needs a network entry with Fraxtal’s chain ID and an RPC before it can show Fraxtal in the network selector.

The RPC you add can see your addresses and supplies the balances MetaMask displays, so take its address from official Fraxtal information or a chain-ID-checked list. The Fraxswap is a decentralized exchange and automated market maker with an embedded time-weighted market maker for swaps and large trades executed over time.

Add Fraxtal in the MetaMask extension

  1. Open MetaMask’s network selector and choose Add a custom network. Keep the official Fraxtal network values available as you enter them.
  2. Enter the network name, RPC URL, chain ID, currency symbol and block explorer URL. Use Fraxtal, https://rpc.frax.com, 252 (hexadecimal 0xfc) and https://fraxscan.com; take the currency symbol from official Fraxtal information.
  3. Save the network and switch to Fraxtal in the selector. MetaMask checks whether the chain ID reported by the RPC matches the one you entered.

    Note: A chain ID mismatch means the RPC may be incorrect or malicious. Don’t approve it; recheck the RPC address against official Fraxtal information.

  4. Alternatively, open the Fraxswap app and review its add-network prompt. Confirm that the requested chain ID is 252 and that the RPC is the official Fraxtal endpoint before approving the prompt.
  5. With Fraxtal selected, compare the wallet’s native balance in MetaMask with the same address on Fraxscan. Matching balances confirm that MetaMask is connected to the expected Fraxtal network.

Once the network is selected and the balance matches, MetaMask is ready for Fraxswap on Fraxtal. The network entry determines which RPC supplies the account’s displayed balance, so keep the verified endpoint in place.

Ready to connect

  • Official Fraxtal values: chain ID 252, RPC https://rpc.frax.com, explorer https://fraxscan.com, and the documented currency symbol.
  • MetaMask extension: Fraxtal appears in the network selector after saving.
  • Connection check: the selected account’s balance matches on MetaMask and Fraxscan.
