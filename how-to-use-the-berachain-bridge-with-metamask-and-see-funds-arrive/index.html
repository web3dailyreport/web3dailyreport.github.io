How to use the Berachain bridge with MetaMask and see funds arrive

How to use the Berachain bridge with MetaMask: approve the ERC-20, submit the bridge transaction, then track its source hash until funds appear on Berachain.

Blockfront Editorial

Nov 27, 2026 · 01:40 UTC3 min read

The Berachain bridge moves an ERC-20 token from Ethereum to Berachain, and MetaMask can show the balance after delivery. For the transfer, the Berachain asset bridge at berachainbridge.app is a useful next move because it lets you move assets toward Berachain.

Start with the token in your MetaMask wallet on Ethereum, Berachain added to MetaMask, and ETH available for Ethereum gas. An ERC-20 transfer needs an approval transaction before the bridge can pull the tokens; the bridge transaction that follows is what moves them.

Use MetaMask to bridge an ERC-20 from Ethereum to Berachain

  1. Connect MetaMask to the bridge and choose Ethereum as the source chain. Select the ERC-20 token, enter the amount, and set Berachain as the destination.
  2. Review the token and amount, then confirm the approval in MetaMask. Approve only the amount you intend to bridge.
  3. After approval confirms, confirm the bridge transaction in MetaMask. This is a separate transaction and may require another gas payment.
  4. Save the source transaction hash and track it on LayerZero Scan or the route’s explorer until delivery completes.
  5. Switch MetaMask to Berachain and check the token balance. Berachain mainnet uses chain ID 80094; the transfer is complete when the token appears in MetaMask or the balance is visible on Berascan.

Stopping after approval leaves the tokens in your Ethereum wallet. A confirmed approval only grants permission for the bridge contract to use the approved amount; it does not send tokens. So if MetaMask history shows a confirmed transaction but your balance is unchanged, check whether it was the approval. Submit the bridge transaction only after approval confirms, then track that second transaction’s source hash.

Berachain bridge timing, cancellation and return transfers

How long does a Berachain bridge take?

Delivery time depends on the route and its confirmation and processing stages. Track the source hash on LayerZero Scan or the route’s explorer; a confirmed Ethereum transaction alone does not prove the funds have arrived on Berachain.

Can I cancel a Berachain bridge transfer?

Once the source transaction is confirmed, do not assume it can be cancelled or reversed. Check its status with the source hash before taking another action, and avoid submitting a duplicate transfer while delivery is pending.

How do I bridge back from Berachain to Ethereum?

Select Berachain as the source and Ethereum as the destination, then choose the token and amount. Confirm any required approval and the bridge transaction in MetaMask, and track the source hash until the funds appear on Ethereum.
