Jupiter token verification: how a mint earns its tag

How Jupiter token verification works: Jupiter checks a submitted Solana mint’s identity, metadata and trading activity before adding its address to the verified list.

Blockfront Editorial

Nov 25, 2026 · 23:57 UTC2 min read

Jupiter verifies a Solana token by reviewing a submitted mint address for identity, accurate metadata and organic trading, then attaching the verified tag to that address.

Jupiter reviews the submitted mint

Jupiter’s review starts with a mint address submitted by a project or community member. The address identifies the token under review; its name and ticker alone cannot establish which token is genuine.

Reviewers check whether the mint matches the project’s claimed identity, whether its metadata is correct and whether it has real trading activity. No single name or badge earns verification on its own: the review considers the mint and the evidence around it.

Say two tokens called BONK appear in Jupiter search. The verified tag belongs to the mint Jupiter has reviewed, so traders can distinguish that address from another mint using the same name.

A rugcheck is a separate risk check for warning signs that could point to a scam or rug pull. For background on what that check adds to a token review, see verify solana token.

The tag follows the mint through Jupiter’s API

Once Jupiter verifies a mint, the tag appears in Jupiter’s interface and in its Token API. The API gives wallets and other apps token data they can use to display the verification status.

That reach explains why a verified badge may appear outside Jupiter. Many wallets and apps read Jupiter’s token API, so a third-party badge often reflects Jupiter’s status for that mint.

The tag helps traders find the reviewed token among lookalikes, but it speaks to the mint’s identity and Jupiter’s review. It is not a rugcheck result: Jupiter’s verified label and a risk check answer different questions.
