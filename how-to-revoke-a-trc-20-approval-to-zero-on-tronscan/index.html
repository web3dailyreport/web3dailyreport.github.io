How to Revoke a TRC-20 Approval to Zero on TRONSCAN

How to revoke a TRC-20 token approval on TRONSCAN: set the token-spender allowance to zero in your account, then confirm the transaction in TronLink.

Blockfront Editorial

Nov 21, 2026 · 12:56 UTC2 min read

A TRC-20 token approval on TRONSCAN is revoked by setting that token-spender allowance to zero, then signing the transaction in TronLink.

Start with TronLink unlocked on TRON mainnet and the address that granted the approval. Keep some TRX available: the on-chain revoke uses Energy and Bandwidth, with fees paid in TRX.

An approval belongs to a token-spender pair, so each router has its own allowance. A router upgrade can change which contract handles a swap; SunSwap's V4-to-V3 swap and liquidity changes are a useful example because its Universal Router is a spender contract.

How do you revoke and verify one allowance?

TRONSCAN sends an approve call with the selected spender and an allowance of zero; confirm that zero appears after the transaction is confirmed.

  1. Open tronscan.org and connect TronLink. Confirm that TronLink is on TRON mainnet and that the connected address is the one that approved the tokens.

  2. Open the connected account's approvals section. Find the TRC-20 token whose allowance you want to remove.

  3. Find the row for the spender contract and click Revoke. Match the contract address to the spender you intend to revoke; do not rely on a displayed label alone.

    Each row represents a separate token-spender allowance. If the same token has approvals for multiple SunSwap routers, revoke each relevant row individually.

  4. Review the transaction in TronLink and sign it. This on-chain approval update costs Energy and Bandwidth, paid in TRX; it does not move your tokens or recover tokens already spent.

  5. After confirmation, return to the approvals section and verify that the allowance reads zero. The row should disappear from the list.

Revoking one router's allowance leaves any other token-spender allowances in place. Once you have removed every row you intended to clear, the next swap of that token through either router requires a new approval transaction. You can then approve the amount requested for that swap in TronLink.
