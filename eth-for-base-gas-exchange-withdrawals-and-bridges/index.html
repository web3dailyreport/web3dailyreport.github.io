ETH for Base gas: exchange withdrawals and bridges

To get ETH for gas on Base, withdraw it directly from Coinbase or bridge ETH from Ethereum; keep a balance on Base before moving USDC or signing transactions.

Blockfront Editorial

Nov 27, 2026 · 22:05 UTC3 min read

A wallet with only USDC on Base needs ETH before it can move that USDC, so withdraw ETH directly to Base or bridge it from Ethereum. The Base bridge is one concrete route because it transfers supported assets between Ethereum and Base. Base has no separate gas token for transactions: fees are paid in ETH held on Base, as Base Docs explains in Network Fees.

For a Coinbase withdrawal, choose ETH, select Base as the network, enter your wallet address and confirm the transfer details. Coinbase Help says users can choose Base when sending crypto to the Base app; the ETH arrives at the same address on Base as the one used on Ethereum. Make sure the sending service supports Base withdrawals and select the matching network.

With a bridge, start with ETH on Ethereum and use a bridge service to move it to Base. The Base bridge requires ETH on Ethereum to pay the Ethereum-side transaction fee, often called L1 gas. A direct exchange withdrawal to Base skips that Ethereum transaction and its L1 gas cost. Across Protocol and Orbiter Finance are other bridge names readers may encounter; compare the route and fees shown before confirming.

Keep some ETH on Base before moving tokens

Base fees combine an L2 execution fee for processing a transaction on Base and an L1 data fee for posting transaction data to Ethereum. Both are paid in ETH, according to Base Docs - Network Fees. The total can vary with network conditions and the transaction, so check the wallet’s fee estimate before signing.

That distinction matters when a wallet holds only USDC. USDC is a token balance, not the ETH balance used to pay network fees, so having USDC on Base alone may leave the wallet unable to send it or approve an onchain action. Fund the wallet with ETH first, leave enough for the next transaction, then move or use the USDC.

Common questions about ETH gas on Base

How much ETH do I need for gas on Base?

There is no fixed amount that covers every transaction. The fee depends on the transaction and current network conditions; check the wallet’s estimate and keep enough ETH to cover it before signing.

Can I pay Base gas fees with USDC?

Base transaction fees are paid in ETH. A USDC balance alone does not provide the ETH needed to move USDC or sign a transaction, so add ETH to the wallet first.

Is there a Base faucet for testnet ETH?

Testnet faucets distribute test ETH for testing, not ETH with value for Base Mainnet fees. For real Base transactions, withdraw or bridge ETH to Base Mainnet.
