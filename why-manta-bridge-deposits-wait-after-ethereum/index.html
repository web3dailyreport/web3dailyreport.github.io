Why Manta Bridge Deposits Wait After Ethereum

Manta deposits wait for Ethereum confirmation and message delivery; rollup batches publish L2 activity for data availability, not a separate deposit approval.

Blockfront Editorial

Oct 4, 2026 · 13:43 UTC2 min read

Manta Bridge deposits can remain pending after an Ethereum transaction because the source-chain transfer must be confirmed and its message delivered to Manta Pacific. Rollup batches publish L2 activity for data availability; they are not a separate approval that each deposit must await.

What happens after an Ethereum deposit?

The deposit first lands on Ethereum, where the bridge records the transfer and locks the asset. Manta Pacific must then process the cross-chain message and credit the corresponding token to the destination address.

Those are separate steps, so an Ethereum confirmation does not guarantee that the Manta balance updates at the same moment. For the wallet-fee details that can affect a submission, see this guide to Manta Bridge gas requirements.

Are L1 batches holding up the deposit?

Usually, “waiting for a batch” describes rollup data publication, not the deposit’s individual bridge message. A batch groups L2 transactions so their data can be made available for the rollup; Manta Pacific uses Celestia for data availability.

A deposit moves in the other direction: its Ethereum transaction supplies the message that Manta Pacific processes. That means a pending L2 credit can reflect confirmation or message processing, while batch publication serves the rollup’s data and verification process.

  • Ethereum transaction pending: the source-chain transaction has not yet been included in a block.
  • Ethereum transaction confirmed, no L2 credit: the bridge message may still be awaiting processing or display.
  • L2 transaction visible, balance absent: check the destination address and token contract on Manta Pacific.

How should users check a pending deposit?

Start with the Ethereum transaction hash and confirm that the transaction succeeded and called the intended bridge. Then check the bridge history or Manta Pacific explorer for the corresponding deposit activity and verify the receiving address.

Do not submit the same deposit again just because the balance has not refreshed; a second transaction can move additional funds. If the Ethereum transaction succeeded but no corresponding L2 activity appears, use the bridge’s support route with the transaction hash. The practical signal of completion is the credited balance on Manta Pacific.
