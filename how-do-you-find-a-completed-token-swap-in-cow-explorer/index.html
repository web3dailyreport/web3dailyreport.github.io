How do you find a completed token swap in CoW Explorer?

Find a completed token swap in CoW Explorer by searching its network for an order ID or wallet address, then confirm Filled and inspect execution amounts and settlement.

Blockfront Editorial

Nov 18, 2026 · 14:53 UTC2 min read

CoW Explorer can identify a completed CoW Swap trade by its order ID or trading address and show the executed amounts and settlement link.

Have the network the trade used and either its Order ID or the wallet address that submitted it. CoW Explorer also accepts a batch transaction hash. The Explorer documentation calls the order identifier “Order ID”; it may show only the first eight characters.

CoW Swap limit orders can fill over time, so the order’s status and fills matter when tracing a trade. To learn more about how cowswap limit orders work, see cowswap limit orders.

How do you find the matching order?

  1. Open explorer.cow.fi and select the network used for the trade. The network narrows your search to the right order records.
  2. Search the Order ID or trading address. If you have the batch transaction hash, you can search that instead. With an address search, use the token pair and submission time to identify the intended trade among the results.
  3. Open the matching order. Its details show the pair, submission time and status, so compare those fields with the trade you meant to make.

How do you confirm the swap settled?

  1. Read the order’s status and confirm it says Filled. CoW Protocol’s Explorer documentation defines Filled as an executed and settled order.
  2. Review the order’s filled amounts and execution details. The order view reports the amount sold and bought; the sold amount includes the fee.
  3. Open the settlement transaction link attached to the Filled order. When the order is fully filled rather than partially fillable, the Explorer documentation identifies this as the on-chain settlement transaction.

A settlement can contain several users’ trades in the same batch. Use the amounts shown on your order to record what your swap sold and bought; the batch transaction’s totals include other orders too.

You are done when the Filled record matches the intended pair and submission time, and its order-specific amounts match the trade you want to recognize. From there, open the settlement transaction in the linked block explorer to view the on-chain record for that batch.
